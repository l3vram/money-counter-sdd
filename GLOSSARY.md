# Glosario de terminología contable

Términos correctos de contabilidad usados en la app, con su nombre viejo (heredado) como referencia.

| Término correcto | Nombre viejo en la app | Qué es |
|---|---|---|
| Venta (comprobante) con arqueo de caja | Conteo | Venta cobrada en efectivo + desglose por denominación |
| Importe a cobrar / Total de la venta | Objetivo | Suma de los productos = lo que se debe cobrar |
| Arqueo de caja (efectivo recibido) | Contado | Conteo físico del efectivo por denominación |
| Diferencia de caja (faltante / sobrante) | Faltante / Excedente | Diferencia entre lo cobrado y el arqueo |
| Inventario / Existencias | Stock | Cantidad disponible de cada producto |
| Ajuste de inventario por merma (baja) | — (nuevo) | Salida de inventario sin venta, por pérdida |
| Venta a crédito → Cuenta por cobrar (CxC) | Fiado / salida con deuda | Venta sin efectivo; crea un derecho de cobro |
| Cobro / Recibo de cobro | Liquidar deuda | Efectivo que entra y cancela una cuenta por cobrar |
| Cierre / Resumen consolidado | Reporte unificado | Consolidación de las ventas del período |

Nota: *"Nota de crédito"* = devolución/descuento posterior; *"Nota de débito"* = cargo extra posterior. Ambas quedan para una fase futura (devoluciones).
